# Pong Game

A simple 2D Pong game built with Python and Pygame Community Edition.

This project follows the Model-View-Controller architecture and basic object-oriented design principles:
- Model: game state and ball/paddle logic
- View: rendering with Pygame
- Controller: input handling and main game loop

## Features
- 1-player mode against a CPU opponent
- 2-player local mode on one keyboard
- Score tracking
- Win condition at 7 points
- Start menu and restart flow
- Single-player survival score based on how long the player stays in the match without conceding a point
- Unlockable paddle colors that are stored between sessions

## Requirements
- Python 3.9+
- pygame

## Install
```bash
python -m pip install -r requirements.txt
```

## Run
```bash
python pong_game.py
```

## Controls
1-player mode:
- Left paddle: W / S
- Right paddle: CPU controlled

2-player mode:
- Left paddle: W / S
- Right paddle: Up / Down

Menu:
- 1 = one-player mode
- 2 = two-player mode
- C = cycle unlocked paddle colors
- Esc = quit or return to menu

## Save data
Progress is stored on disk in the OS-specific application data directory for this game:
- Windows: %APPDATA%\pong-game\pong_progress.json
- macOS: ~/Library/Application Support/pong-game/pong_progress.json
- Linux: ~/.local/share/pong-game/pong_progress.json

This stores the best survival time and unlocked paddle colors between game sessions.
